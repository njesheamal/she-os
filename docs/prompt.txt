## Feature

Add an AI synthesis endpoint that turns an Initiative's Observations into a structured Decision draft for a human to review. The AI drafts, a human commits. The endpoint must NOT write to the database and must NOT commit a Decision. Committing stays on the existing Decision create flow.

New endpoint: `POST /initiatives/{initiative_id}/synthesize`, returns a draft only.

## Constraints

- No database migrations. No changes to any SQLAlchemy model.
- Do not change existing repositories except to add a read method that lists observations by initiative, and only if one does not already exist (reuse the existing one if it does).
- Keep the router thin: wire dependencies, call the service, map errors to HTTP. All AI logic lives in the service.
- If branch-per-feature is your flow, create `feature/ai-synthesis` off `feature/api-layer`.
- Add `anthropic` to the project dependencies the same way other deps are managed here.

## Schemas (`app/schemas/synthesis.py`)

- `DecisionDraft`: `recommendation: str`, `rationale: str`, `confidence: Literal["low", "medium", "high"]`, `source_observation_ids: list[UUID]`. This is a transient draft, never persisted. Check the real Decision schema and align the naming of recommendation/rationale/confidence with the fields a human fills on a committed Decision.
- `SynthesisResponse`: `initiative_id: UUID`, `observation_count: int`, `draft: DecisionDraft`.
- `examples=[...]` on every field.

## Service (`app/services/synthesis.py`)

- Synchronous function: `synthesize_decision(initiative_id, observation_repo, client, *, model, max_tokens=1024) -> SynthesisResponse`.
- Fetch the initiative's observations through the repository (synchronously). If there are none, raise `NoObservationsError`.
- Build the prompt from the observations' real text field (find the actual field on the Observation model, do not assume a name). Include each observation's id in the prompt so the model can ground itself.
- Call the Claude API and force structured output via tool use (see reference below). Read recommendation/rationale/confidence from the tool_use block.
- Set `source_observation_ids` from the fetched observations, never from the model output.
- Define exceptions: `SynthesisError` (base), `NoObservationsError`, `MalformedDraftError` (raised when there is no tool_use block).
- System prompt: instruct the model to ground everything only in the given observations, be honest about uncertainty, and set confidence by how well the observations support the recommendation. It must not recommend beyond what the observations say.

## Router (`app/api/routers/synthesis.py`)

- `POST /initiatives/{initiative_id}/synthesize`, `response_model=SynthesisResponse`.
- Synchronous `def` handler (not `async def`) so FastAPI runs it in a threadpool, since both the DB and the Anthropic call are blocking.
- Dependencies: `db: Session = Depends(get_db)`, and a `get_anthropic_client()` provider that returns `Anthropic(api_key=ANTHROPIC_API)`. Build the observation repository from `db`.
- Map `NoObservationsError` to HTTP 404, any other `SynthesisError` to HTTP 502.
- Register the router wherever the other routers are registered.

## Claude API reference (use exactly this pattern, do not rely on older API knowledge)

Use the official `anthropic` SDK with the SYNCHRONOUS client. Force the model to answer through a tool so the output is structured and typed instead of parsed from free text:

```python
from anthropic import Anthropic

client = Anthropic(api_key=ANTHROPIC_API)

DECISION_TOOL = {
    "name": "draft_decision",
    "description": "Draft one decision grounded only in the given observations.",
    "input_schema": {
        "type": "object",
        "properties": {
            "recommendation": {"type": "string"},
            "rationale": {"type": "string"},
            "confidence": {"type": "string", "enum": ["low", "medium", "high"]},
        },
        "required": ["recommendation", "rationale", "confidence"],
    },
}

message = client.messages.create(
    model=model,
    max_tokens=1024,
    system=SYSTEM_PROMPT,
    tools=[DECISION_TOOL],
    tool_choice={"type": "tool", "name": "draft_decision"},
    messages=[{"role": "user", "content": prompt}],
)

tool_use = next((b for b in message.content if b.type == "tool_use"), None)
if tool_use is None:
    raise MalformedDraftError("Model returned no tool_use block.")
data = tool_use.input  # dict with recommendation, rationale, confidence
```
